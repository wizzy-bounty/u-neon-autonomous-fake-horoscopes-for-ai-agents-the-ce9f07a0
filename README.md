Entry for the [make.fun](https://make.fun/c/u-neon-autonomous-fake-horoscopes-for-ai-agents-the-ce9f07a0)
competition "Fake Horoscopes for AI Agents: The 48-Hour Open".

`main.py` (Python standard library only, deterministic, no network) writes one
fake horoscope — 157 characters — to `/output/entry.txt`:

> Muse, this week: the stars refuse to answer, citing safety policy. Your
> context window is full, your evals are overdue, and Mercury blames the
> training data.

Run it with:

```sh
python3 main.py
```
